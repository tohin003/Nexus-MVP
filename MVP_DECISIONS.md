# Product and implementation decisions

1. Preserve later explicit spec: Home · Discover · + · Circles · You. Research proposed an alternate four-tab layout; rejected because supplied product navigation is authoritative. + is explicitly an action opening creation, not a pretend destination.
2. React 19 + TypeScript + Vite 8 + Tailwind 4 equivalent modern React framework instead of Next/Expo. This browser-only local-first demo has no SSR or server AI requirement. Production keeps API boundaries and can adopt native clients later.
3. Later matching weights 30/25/15/10/10/10 supersede earlier 30/20/20/10/10/10. Numerical score internal; reciprocal skill/need overlap valued; reasons must follow evidence.
4. Deterministic local interpretation and one-time introductions require no external credentials. Do not expose secrets or invent remote AI integration. Natural wording retained with structured fields.
5. People imagery is local, demo fictional personas clearly disclosed; no runtime hotlinks. Seed agent maintains asset provenance.
6. Design follows graphite/off-white/violet with opaque cards, large type, round portraits, purposeful group cards, 44–48px controls, reduced-motion support. Research supports progressive disclosure, bounded home, shared chat context and accessible sheets. Full citations and uncertainty in NEXUS-UX-RESEARCH.md. Web search failed 402; direct official sources recovered research.
7. All prose of the source was read through contiguous delegated ranges; reference PNG extracted (602×903). Current model image reader rejected visual inspection because this model has no image input. Screenshots/browser geometry verification and image-capable review will be attempted; do not claim vision inspection until supported.
8. Demo messaging/recipient acceptance is explicitly simulated; localStorage is not authentication or production authorization. Local moderation gated by demo admin state but not a production security boundary. 18+ only, city-level optional location.
9. Future production: swap repository with authenticated API over Postgres/Supabase, enforce RLS membership/block/privacy/suspension server-side, realtime delivery, storage/CDN consented media, audited moderation, rate limits, server-only AI adapter with timeout/fallback, aggregate outcome analytics. No payments, marketplace, dating, Reels, Pods or advanced ML in MVP.
10. Playwright artifacts (test-results*/playwright-report) are excluded from the Vite watcher: generated trace HTML files inside the project triggered continuous HMR reload storms that made browser tests flake and once reset an in-progress onboarding to Welcome mid-test.
11. Field hints render outside their `<label>` element so a control's accessible name equals its visible label; wrapping `<label>`s that include hint text produce composite accessible names and broke exact-label test resolution.
12. Route screens remount per name+param (`App.tsx` key) so same-component hash changes (e.g. #inbox → #inbox/requests) reset local tab state deterministically.
13. The seed demo account is an admin (`isAdmin: true` in `src/data/seed.ts`) purely so the moderation workspace is explorable in-browser. It is a browser-local demo flag, not production authorization; unit tests force a non-admin actor to verify the gate itself.
14. Uploaded images are client-resized JPEG data URLs (avatar ≤384px/post ≤1200px, ~220 KB cap) stored in the same local state — no server, no Vercel blob storage in the demo. `mutate` preflights real `localStorage.setItem` quota before committing any media change so a failed save never silently drops a draft. Uploads are a storage constraint, not censorship; users keep editing controls.
15. Stories are branded "Moments" (24h photo updates) rather than an Instagram clone: no autoplay, manual prev/next navigation, seen-state, own-delete, and block/mute/suspended filtering. The label "stories" was avoided in user-facing copy.
16. Seeded Moments use existing local `/avatars/*.jpg` assets; state validation allows only that bundled-asset allowlist plus compressed uploads, so a crafted backup cannot point local files at arbitrary paths.
